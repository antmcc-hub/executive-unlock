# Executive Unlock Agent Instructions

This repo is a tiny static site for AI Executive Unlock at `aiexecutiveunlock.com`.

## Map

- `index.html` is the full site.
- `CNAME` points GitHub Pages/custom domain to `aiexecutiveunlock.com`.

## Build, Test, Ship

- There is no build step.
- Verify by opening `index.html` locally or serving the folder with a static server.
- Shipping path is GitHub-only via the repo's hosting/deployment integration. Do not manually deploy outside GitHub.

## Guardrails

- Keep this repo intentionally simple. Avoid adding frameworks unless Ant explicitly asks.
- Preserve the custom domain in `CNAME`.
- Any visual/content change should be checked on mobile and desktop widths.
